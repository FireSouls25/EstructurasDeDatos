# Taller: Listas Circulares Dobles – Reloj Analógico  
**Autor:** David Enmanuel Castillo Florez

Este proyecto implementa un reloj analógico en Python, utilizando listas circulares dobles. La interfaz está desarrollada con la biblioteca `tkinter`, incluida por defecto en Python.

## Características

- Permite cambiar la posición de la manecilla de las horas utilizando el mouse.
- Es posible establecer una hora específica mediante los botones ubicados debajo del reloj.
- Al iniciar el programa, el reloj comienza desde la hora 00:00:00.

## Requisitos

- Python 3
- La biblioteca `tkinter` (incluida por defecto en instalaciones estándar de Python)

## Cómo usar

1. Clona el repositorio:
```bash
git clone https://github.com/FireSouls25/EstructurasDeDatos.git
```

2. Ejecutar el programa
    - En windows dar doble click sobre el archivo run.bat
    - En otros dispositivos abrir una terminal en la carpeta del repositorio y escribir ```python Frontend.py``` o dar doble click sobre el archivo Frontend.py
